# Wisp

A lightweight direct-messaging app built with React, Vite and AppDeploy.

## Features

- Sign up or log in with email or Google.
- Create a display name and unique username.
- Find people by display name, username, or exact email address.
- Start private one-to-one conversations.
- Send messages with live cross-client updates.
- Responsive desktop and mobile layout.

## Run locally

```bash
npm install
npm run dev
```

The AppDeploy client SDK is injected by the AppDeploy platform. Authentication, protected API routes, persistence and realtime delivery are configured for the deployed app.
